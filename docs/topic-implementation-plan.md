# 自然地理专题实施计划

1. **选取数据与交互口径。** 明确洋流和大气的统计月份、气候常值的基准期、造山重建的年代和时空分辨率。核实数据下载与许可，在技术设计中记录可重跑的预处理步骤。
2. **接入专题导航和地图。** 用 URL 片段定位四个专题，复用全球陆地底图。实现月份选择、播放、地图点选及数据加载异常恢复。日照的观测时刻和地点留在本专题。
3. **实现洋流与大气环流。** 海洋显示近表层流速、流向和海温。大气显示 850／200 hPa 风场，以及同月的纬度–气压剖面。检查南北和东西方向、缺测区域及跨日期变更线。
4. **实现造山运动。** 用离散年代推进印度与欧亚板块的重建，在可旋转地球上标出参考点和轨迹。同步显示对应阶段的教学剖面和简短说明。
5. **实现气候剖面。** 可沿固定经线或纬线选择剖面，地图与月均气温、月降水量和陆地高程曲线联动。加入可复现的预设路线和无数据处理。
6. **验证与交付。** 校验数据文件、单位、关键地理样本和缺测值。运行生产构建、现有测试和新增交互回归。检查触控布局、减弱动画、链接直达、前进／后退、首访引导和跨专题切换。

| 专题 | 交互验收 |
| --- | --- |
| 洋流 | 切换月份使流场和读数同步更新。切换海温底色保持流向图层。点选海陆时分别处理有效和缺测样本。 |
| 大气环流 | 切换层次会改变风场和剖面上的气压高亮。月份改变同时更新水平风和纬度–气压剖面。高地下面的等压面按月均地面气压掩蔽。 |
| 造山运动 | 切换年代使轮廓、示踪点和剖面一起变化。可旋转地球并复位到研究区域。每个年代使用实际重建帧。 |
| 气候剖面 | 切换月份或变量更新底图。切换固定经纬度、点地图或选预设都会移动剖面。三项指标可沿同一位置查看，数据缺口保留。 |
| 日照回归 | 原入口、使用引导、2D／3D、节气、两地曲线、播放与全屏演示继续通过现有测试。 |
